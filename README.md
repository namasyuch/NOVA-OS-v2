# NOVA OS
NOVA OS is my WebOS 1 project.
I made it from scratch using HTML, CSS and JavaScript.

## Live Demo
https://namasyuch.github.io/NOVA-OS-v2/

## Features
* Full-screen desktop background
* Notes app
* About app
* Calculator
* Clock
* Draggable windows
* Open and close buttons

## What I learned
I learned more about JavaScript while making the windows draggable and while building the calculator and clock.

## Challenges
Making the windows draggable was the hardest part for me. I had to understand how mouse position and window position work together.

## What I'm proud of
I'm proud that I rebuilt the project from scratch and got the main features working.

## Testing
I tested the apps, buttons, calculator, clock and window dragging.
